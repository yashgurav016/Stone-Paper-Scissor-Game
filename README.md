# 🎮 Rock Paper Scissors Game

A browser-based Rock Paper Scissors game built using HTML, CSS, and JavaScript. Play against the computer, test your luck, and track scores as you compete in each round.

## ✨ Features

* 🪨 **Three Choices:** Select Rock, Paper, or Scissors.
* 🤖 **Random Computer Moves:** The computer randomly generates its choice for every round.
* 🏆 **Winner Detection:** Automatically determines the winner based on the game rules.
* 📊 **Live Score Tracking:** Keeps track of the player's and computer's scores.
* 🤝 **Draw Detection:** Identifies rounds where both choices are the same.
* 🎨 **Interactive UI:** Includes hover effects, dynamic result messages, and color changes based on the game outcome.

## 🛠️ Technologies Used

* **HTML5** — Structures the game interface.
* **CSS3** — Styles the layout, choices, scoreboard, and interactive effects.
* **JavaScript** — Implements game logic, random computer choices, event handling, and score updates.

## 🎯 How to Play

1. Open the game in your web browser.
2. Choose Rock, Paper, or Scissors by clicking the corresponding image.
3. The computer randomly selects its move.
4. The game displays the result of the round.
5. The scoreboard updates automatically when either the player or computer wins.
6. Play multiple rounds and try to beat the computer!

## 📜 Game Rules

* **Rock beats Scissors**
* **Scissors beats Paper**
* **Paper beats Rock**
* Identical choices result in a draw.

## 🚀 Getting Started

1. Clone this repository:
